How it works

Everything you need, nothing in the way

A small set of tools that work together, so you can spend your time on the parts only you can do.

  • Capture anything

    Save the pieces you like the moment you find them, with every detail intact.

  • Arrange freely

    Move things around until they click. Keep what works, swap the rest.

  • Keep the best parts

    Take only the layout, the look or the words, whichever you need.

  • One consistent style

    Colours, type and spacing settle into a single set you can trust.

  • Ready to hand off

    Everything is packaged neatly for whoever builds it next.

  • Try every version

    Branch off, compare side by side and come back whenever you like.
