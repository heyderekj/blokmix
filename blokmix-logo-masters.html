Logo masters

The final vector files behind the Blokmix brand guide. The wordmark is outlined, so it no longer depends on a font. Every file is made of filled shapes only, and the favicons are redrawn on whole pixels.

01 · Wordmark

Wordmark

Use the ink version on light backgrounds and the paper version on dark. On hot pink, the block turns ink.

02 · Icon

App icon: the grab

A glossy pink block grabbed and lifted out of its slot on a dotted canvas. The master is rendered in 3D in Blender. Flat vector versions drawn from the same geometry cover small sizes and anywhere a vector is needed.

03 · Lockups

Lockups

In the horizontal lockup the icon matches the letter height. In the stacked lockup it is twice the letter height. Both use a half-block gap. On light backgrounds the lockup uses the ink-tile icon and on dark backgrounds the light tile, so the icon’s silhouette always holds.

04 · Construction

How it’s built

Every measurement comes from the wordmark’s block, so the system holds together when someone redraws a piece.

ascender 725
x-height 526
baseline 0
60
60
Letters
Archivo at width 125, weight 900, outlined. Tracking −45 units. Kerning k–m −10, i–x +6.
The block
One x-height square (526 units) on the baseline, with 60 units of space on each side, the same as the l’s stem.
Corners
Every block in the system has a corner radius of 7.5% of its side.
Icon layout
On a 1024 canvas: dots every 64 px, a 352 px slot carved in at (208, 472) with a 66 px radius, and a 392 px block (19% radius) lifted above the canvas, rotated −9° and tilted toward the light. Key light from the top left. The tile is a superellipse (n = 5).
Rendering
Built and rendered in Blender (Cycles) with the Standard view transform, so the pink stays true at #FF5CB0. The script is in source/blokmix_blender.py. The flat vector versions use solid fills only and the same geometry.
Clear space
One block on every side of any logo.
Minimum size
Wordmark 80 px or 20 mm wide. Rendered icon from 64 px, the flat icon without dots from 24 to 63 px, and the pixel-snapped favicons at 16 and 32 px.
